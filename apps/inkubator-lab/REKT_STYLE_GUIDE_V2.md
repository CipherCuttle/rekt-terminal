# REKT INK(CUBATOR) — Style Guide V2

## Core thesis

**Post-digital REKT instrument.**

REKT INK(CUBATOR) is a broadcast dossier for an underground builder culture. It should feel like a premium object recovered from a corrupted internet: precise enough to trust, damaged enough to feel alive, and funny enough to share.

## Visual equation

`clean artifact core + degraded signal environment + hostile-cute REKT identity`

## Keep

- Near-black instrument surfaces.
- Ink purple for environment, structure, and context.
- Acid green for truth, active state, and positive signal.
- Cyan and orange only for rare signal breaches.
- One-pixel seams and shared surfaces instead of floating SaaS cards.
- Mono metadata, tabular numbers, compact labels, and oversized display type.
- Real REKT / Chibi artwork or approved marks as the visual anchor.
- Tight crops, field notes, specimen numbers, warnings, and broadcast language.
- Degen humor in diagnostics, naming, rarity, and lore; never as cheap decoration.

## Reject

- Terminal cosplay as the main identity.
- ASCII heroes, cursor masks, fake hood SVGs, or “find the logo in the noise.”
- Generic crypto dashboards, bento-card SaaS layouts, and faux product analytics.
- Rainbow gradients, aurora blobs, glassmorphism, soft startup polish, and decorative WebGL.
- Multiple simultaneous effects. One meaningful ambient signal per viewport maximum.
- Invented visual identity where an actual REKT mark or artwork should be used.

## Page grammar

1. **Instrument header** — identify the transmission and current state.
2. **Artifact hero** — one strong still composition that works without motion.
3. **Signal** — state the cultural thesis in blunt language.
4. **Field log** — show the invited builders as selected subjects, not generic avatars.
5. **Weight** — clarify what the operator and REKT each contribute.
6. **Broadcast loop** — show how BUILD → CLIP → SHARE → ATTENTION → NEW BUILDER compounds.
7. **Open channel** — one decisive CTA.

## Motion

Motion may reveal signal, scan a specimen, or move a broadcast ticker. It must never carry comprehension. Reduced-motion users receive the same information in a static composition.

## Copy rule

Short, declarative, slightly hostile. The governing copy is:

- MAKE DEGENS SHIP.
- BAD IDEAS. WORKING SOFTWARE.
- SHIP > TALK.
- WORKING URL OR GTFO.

## Acceptance test

At a glance, the page must feel like **REKT culture turned into a live instrument**, not an agency landing page explaining a community program.
