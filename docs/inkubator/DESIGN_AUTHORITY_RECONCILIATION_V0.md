### Global material thesis

`WHITE/OFF-WHITE CHASSIS + BLACK PRINT + PURPOSEFUL DARK CATHODE WELLS + CYAN OBSERVED/LIVE SIGNAL + SPARSE ORANGE ACTION/ATTENTION + SELECTIVE REKT VIOLET + REKT-SPECIFIC LINE ART`.

### Truth and signal semantics

- `CLAIMED != OBSERVED != PROVEN`.
- Acid green = PROVEN only.
- Verifier PASS != accepted Ship proof.
- No public surface invents private state or unsupported event kinds.
- No event/ceremony motion without an authorized projection delta.
- Ambient machine life is allowed only when it does not masquerade as activity.

- SHELL — orientation/common machine language.

- PROJECT — one project's current locus, provenance and trajectory.

Cross-surface context may quote/link but may not become a second owner.
